# 규칙 하나로 부품 만들기 — 웹 데모

기초스튜디오 4 · Project 02 · 임종훈 분반

`index.html` 한 파일이 전부입니다. 설치할 것도, 빌드할 것도 없습니다.
브라우저로 파일을 열면 바로 움직입니다.

---

## 이 페이지가 하는 일

판재를 쌓아 입체를 만드는 규칙 하나를 두고, 값을 바꾸면 이 넷이 같이 바뀝니다.

| 보이는 것 | 뜻 |
|---|---|
| 정면 그림 | 쌓았을 때 어떤 실루엣이 되는가 |
| 전개도 | 실제로 잘라야 할 부품 전부 |
| 부품 수 · 절단 길이 · 면적 | 돈과 시간 |
| 합판 1장 안에 들어가는지 | 조건을 넘었는지 |

마지막 줄이 핵심입니다. 화면에서 슬라이더를 밀면 **조건을 넘는 순간이 빨갛게 보입니다.**

## 규칙은 함수 하나

`index.html` 안에서 이 부분만 고치면 형태가 달라집니다.

```js
function radiusAt(u, a, P) {
  // u : 아래(0) ~ 위(1)      a : 둘레를 도는 각도(라디안)
  // 돌려주는 값 : 그 자리의 반지름 배율
  ...
}
```

지금은 네 가지가 들어 있습니다. 모래시계, 원뿔대, 배흘림, 꽃잎.
자기 팀의 규칙으로 이 함수를 바꾸세요. 나머지 코드는 건드릴 필요가 없습니다.

슬라이더를 더 만들고 싶으면 위쪽 HTML에 `<input type="range" id="...">`를 하나 추가하고,
아래쪽 `const ids = [...]` 배열에 그 id를 넣으면 됩니다.

## 웹에 올리기

계정 두 개가 필요합니다. **GitHub**(코드를 두는 곳)와 **Vercel**(주소를 만들어 주는 곳).
Vercel은 GitHub 계정으로 바로 로그인됩니다.

### 1. GitHub에 올린다

웹에서 하는 방법이 가장 쉽습니다.

1. github.com에서 **New repository** → 이름을 정하고 **Public**으로 만든다
2. 만들어진 화면에서 **uploading an existing file** 링크를 누른다
3. `index.html`을 끌어다 놓고 **Commit changes**

명령줄이 익숙하면 이렇게 해도 됩니다.

```bash
git init
git add index.html README.md
git commit -m "웹 데모 첫 버전"
git branch -M main
git remote add origin https://github.com/<계정>/<저장소>.git
git push -u origin main
```

### 2. Vercel로 주소를 만든다

1. vercel.com → **Continue with GitHub**로 로그인
2. **Add New… → Project** → 방금 만든 저장소를 **Import**
3. 설정은 건드리지 않고 **Deploy**
4. 30초쯤 뒤에 `https://<이름>.vercel.app` 주소가 나온다

### 3. 고칠 때

GitHub에 다시 올리기만 하면 Vercel이 알아서 새로 배포합니다.
주소는 그대로입니다.

## 팀 작업 요령

- 한 사람이 저장소를 만들고 나머지를 **Collaborator**로 넣으면 같이 고칠 수 있다
- 파일 하나라서 두 사람이 동시에 고치면 충돌한다. **누가 언제 고칠지 먼저 정할 것**
- 규칙을 바꿀 때마다 무엇을 왜 바꿨는지 커밋 메시지에 한 줄 남긴다. 그 기록이 나중에 패널 재료가 된다

## AI에게 시킬 때

이 페이지도 규칙을 말로 설명해서 만든 것입니다. 잘 되는 요청과 안 되는 요청의 차이는 이렇습니다.

**안 되는 요청** — "멋있는 스툴 만들어 줘"

**되는 요청** — "층마다 반지름이 sin 곡선으로 변하고, 층마다 6도씩 돌아가고,
가운데에 지름 45mm 구멍이 뚫린 적층 구조를 만들어 줘. 부품 수와 총 면적도 같이 보여 줘."

값의 이름과 범위를 말할 수 있으면 코드는 나옵니다. **틀린 치수가 나왔던 자리와 어떻게 고쳤는지 기록해 두세요.**
